# Changelog

All notable public changes to TokenCue are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows a developer-preview versioning scheme until the first signed release.

## [Unreleased]

- Documentation reorganized into a single English documentation set under `docs/` with optimized file names.
- Root guides and platform READMEs rewritten for clarity and cross-link consistency.

## [0.1.0] - 2026-08-08

### Added

- Initial public TokenCue source repository.
- Windows desktop application (Tauri 2 + React + Rust) and `tokencue` CLI.
- macOS desktop application (SwiftUI / AppKit) and Swift CLI (source complete; Mac validation pending).
- Shared provider contracts for **67** providers, design tokens, locale checks, and plugin fixtures.
- Privacy-first onboarding, secure credential storage boundaries, notifications, usage and spend views, and native tray behavior.
- Community guidelines, security reporting process, contribution instructions, and continuous integration.

### Notes

This version is a **developer preview** and does not include signed release binaries, notarized installers, or automatic updates.
